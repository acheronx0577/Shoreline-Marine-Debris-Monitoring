# Shoreline Marine Debris Monitoring

An independent, small-scale study of recurring debris at one accessible shoreline, using NOAA's Marine Debris Monitoring and Assessment Project (MDMAP) method to inform a local cleanup or prevention action.

## The question

At one shoreline site, which visible debris categories recur across standardized visits, and what local action is supported by those observations?

The goal is a useful local baseline, not an ocean-wide estimate or an unsupported claim about where individual items came from.

## Approach

NOAA's current MDMAP guidance uses a 100-meter site and at least four randomly selected transects per survey. Each transect is 5 meters wide and runs from the back barrier to the water. NOAA encourages repeated monitoring at the same location, typically monthly. One visit is a snapshot, not a trend.

Record site and survey conditions and compare repeated visits with consistent effort. The Monterey Bay National Marine Sanctuary's 2023 report already summarizes broad patterns across five citizen-science programs and 276 miles of shoreline, so this project should focus on a specific local pattern and response.

## Data and licensing

- NOAA's [MDMAP explorer](https://marinedebris.noaa.gov/our-work/monitoring/marine-debris-monitoring-and-assessment-project) allows public data exploration and export without a login. Submitting observations requires an account.
- The exact reuse terms for every exported record have not yet been confirmed. This repository contains no NOAA exports or field records. Check the export metadata and NOAA terms before redistributing record-level data.
- The MIT license here applies only to original materials in this repository. It does not grant rights to NOAA records, protocols, photos, or other third-party materials.

## Status

Project setup only. No shoreline has been selected, no NOAA records have been downloaded, and no field observations or results are claimed.

This is an independent student project; it is not an official NOAA or MBARI project or endorsement.
